# Tourvista - Travel Discovery & Itinerary Planner

Tourvista is a modern travel discovery web application built with React, TypeScript, Tailwind CSS, and Supabase. Discover top destinations, curate itineraries, explore interactive maps, and view TripAdvisor-powered travel insights.

## Features
- **Destination & Place Discovery**: Find hotels, restaurants, tours, and attractions.
- **Interactive Map View**: Powered by `@vis.gl/react-google-maps`.
- **Authentication & Cloud Itinerary Sync**: Powered by Supabase.
- **TripAdvisor Integration**: Curated travel recommendations and reviews.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
